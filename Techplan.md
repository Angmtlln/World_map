# Фотокарта мира, технический план

Идея. Серая карта мира, по клику на страну добавляется фото, фото обрезается по контуру страны. Внутри страны галерея всех снимков. Страны плюс регионы России. Проект живёт в GitHub репозитории, хранение фото в перспективе на Google Диске.

## Решения

- Веб приложение, PWA, не нативное. GitHub Pages, бесплатно, открывается с телефона и ноутбука.
- Стек. Vite, TypeScript, React, d3-geo, topojson-client, d3-zoom, idb для IndexedDB.
- Без бэкенда. Хранение локальное, синхронизация с Google Диском как второй этап.

## Геометрия

- Natural Earth, public domain.
- ne_110m_admin_0_countries для стран, ne_10m_admin_1_states_provinces с фильтром iso_a2 = RU для регионов России.
- Конвейер mapshaper, упрощение и квантование, целевой размер topojson до 500 КБ.
- Ключи. ISO 3166-1 alpha-3 для стран, ISO 3166-2 для регионов России.
- Россию убрать из слоя стран, чтобы контуры не накладывались.
- Проекция Equal Earth.

## Заливка фото по контуру

SVG, один path на территорию. Заполнение через pattern с patternUnits="userSpaceOnUse" и вложенным image. Паттерн в координатах карты, поэтому зум и панорамирование работают без пересчёта.

Редактор ракурса. Большой контур страны, фото под ним, жесты перетаскивания и масштабирования. Сохраняются три числа, смещение по x, смещение по y, масштаб, в координатах относительно bbox территории.

## Изображения

Три версии через canvas и WebP. thumb 256 px, map 1024 px, full 2048 px. Ориентация из EXIF через createImageBitmap с imageOrientation = from-image. Из EXIF также можно взять дату съёмки и координаты и подставить страну автоматически.

## Google Диск

- OAuth через Google Identity Services, scope drive.file. Доступ только к файлам, созданным приложением. Скоуп несенситивный, нужна лишь базовая верификация, для личного использования достаточно режима Testing со своим аккаунтом в тестовых пользователях.
- Прямой src на файл Диска не работает. Нужен запрос files/{id}?alt=media с Bearer токеном и blob URL, поэтому обязателен локальный кеш.
- Токен живёт час, refresh token в браузере не выдаётся, при каждом открытии нужен тихий повторный запрос.
- Альтернатива для публичной карты, Supabase Storage или Cloudflare R2.
- Фото в git репозиторий не кладём.

## Пограничные случаи

- Мелкие страны и острова плохо нажимаются, нужен поиск и список территорий.
- Чукотка переходит через 180 градусов.
- Спорные границы, зафиксировать один вариант Natural Earth.
- Порог сдвига, чтобы отличать клик от перетаскивания.

## Этапы

0. Подготовка данных.
1. Серая карта, клик, локальное хранение.
2. Редактор ракурса и галерея.
3. Синхронизация с Диском.
4. Полировка, поиск, статистика, экспорт.
